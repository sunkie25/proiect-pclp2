# Proiect PCLP2 - Slot Machine
![slot](https://i.imgur.com/vwnRe7m.png)
- sunt disponibile 5 linii de castig; panoul de joc este format din 3 linii cu cate 5 coloane
- userul are la dispozitie 4 mize: 5, 10, 50 si 100 coins; acesta primeste 10000 coins la inceputul jocului
- pentru a face jocul mai putin plictisitor, sunt disponibile 3 stiluri de interfata: classic, cartoon si neon
